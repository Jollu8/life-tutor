# Life in Bloom

Мобильная страница с 608 советами о жизни, поиском, личным планом и календарём.

Сайт: https://jollu8.github.io/life-tutor/

Название проекта — **Life in Bloom** («Жизнь в цвету»). Предлагаемое новое имя репозитория — `life-in-bloom`; текущий репозиторий не переименован.

## Возможности

- 608 карточек, 33 темы, поиск и фильтр доказательности.
- Личный список: добавление советов и собственных дел, галочки выполнения.
- Автоматическая закладка: последняя видимая карточка, поиск, фильтры, раскрытые подробности. При возвращении нажмите «Продолжить чтение».
- Скачивание календарного события `.ics` или открытие Google Calendar.
- Экспорт и импорт личного плана в JSON.
- Мягкий голубой интерфейс, адаптивная вёрстка без сборки и внешних шрифтов.

План и место чтения хранятся в `localStorage` этого браузера. Это не аккаунт и не облачная синхронизация: очистка данных сайта удаляет их. Резервная копия переносит задачи; закладка чтения остаётся в браузере.

## Локальный запуск

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Открытие `index.html` через `file://` не поддерживается: данные загружаются через `fetch`.

## Публикация

В Settings → Pages выбран Source: **GitHub Actions**. Push в `main` запускает `.github/workflows/pages.yml`. Workflow проверяет комплектность данных и публикует только файлы сайта. Все ссылки на ресурсы относительные; сайт работает и под префиксом репозитория.

## Контент и перевод

Оригинал: [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter), Unlicense. Данные извлечены из автономного HTML от 25 сентября 2026 года, исходный коммит `8276cae`.

- `assets/advice.json` — оригинальные 608 записей на китайском, включая ссылки на источники.
- `assets/advice.ru.json` — русская версия. Темы и заголовки отредактированы; первые шесть кратких пояснений адаптированы вручную. Длинные пояснения — **непроверенный машинный перевод** Argos Translate (китайский → английский → русский). Возможны смысловые ошибки, включая единицы измерения и валюты. На странице это обозначено; у каждой карточки есть ссылка на оригинал.
- Правовые нормы, выплаты и номера служб относятся к указанным в оригинале странам. Это перевод, а не адаптация законодательства и медицины для России.
- `tools/translate.py` — возобновляемый локальный перевод; требует моделей Argos `zh_en-1_9` и `en_ru-1_9`, `ctranslate2`, `sentencepiece`. Модели и временный кеш в репозиторий не входят.
- После повторного перевода выполните `python3 tools/polish.py` для восстановления редакторских заголовков.

## Проверка

```sh
python3 tests/data.py
node --check app.js
```

Браузерная проверка `tests/browser.cjs` использует Playwright. Установите его во временный каталог и запустите с локальным HTTP-сервером:

```sh
npm install --prefix /tmp/life-bloom-browser playwright
NODE_PATH=/tmp/life-bloom-browser/node_modules node tests/browser.cjs
```

По умолчанию используется установленный Google Chrome для macOS. Путь можно задать через `CHROME_PATH`, адрес сайта — через `TEST_URL`. Проверяются мобильная вёрстка, фильтры, задачи, перезагрузка, JSON-резервная копия, `.ics` и возврат к месту чтения.
