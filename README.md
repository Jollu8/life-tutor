# Life in Bloom — Россия и Москва

[Открыть сайт](https://jollu8.github.io/life-tutor/)

Российская редакция руководства о повседневной жизни: **71 карточка в 19 темах**. Из них 11 относятся к Москве, 13 — ко всей России, 47 содержат общие рекомендации или практические идеи. Региональные сведения сверены с источниками 27 сентября 2026 года.

## Что есть на сайте

- Компактный голубой интерфейс для телефона и компьютера.
- Поиск, темы, фильтры «Россия и Москва», «Вся Россия», «Только Москва».
- Отдельное указание основания: официальный источник, рекомендации организаций или практическая идея. Старые оценки A/B/C не переносятся на новые тексты.
- Личный план, собственные задачи, галочки, экспорт и импорт JSON.
- Продолжение чтения с сохранением карточки, региона, фильтров и раскрытых подробностей.
- События `.ics` и Google Calendar; в описание попадают российский текст и актуальные источники карточки.

Данные пользователя остаются в `localStorage` текущего браузера. Аккаунтов, аналитики и облачной синхронизации нет. Очистка данных сайта удаляет локальный прогресс; резервная копия переносит задачи, но не закладку чтения.

## Редакционная политика

Это самостоятельная адаптация, а не замена слова «Китай» на «Россия». Все опубликованные пояснения переписаны. Для российских норм и московских сервисов приведены ведомство или оператор, ссылка и дата проверки. Услуги могут зависеть от регистрации, полиса, возраста, доходов и других условий; сайт не обещает их автоматическое получение.

Для общих рекомендаций используются источники ВОЗ, CDC, МЧС и CISA. Практические идеи по организации быта явно помечены как редакционные: им не присваивается научная доказательность. Медицинские карточки не заменяют назначения врача. Проверка источника означает редакционную сверку, а не экспертизу юриста или врача.

Из 608 исходных записей 60 получили новую редакцию; 548 исключены из основной выдачи из-за неподтверждённой российской применимости или качества перевода. Добавлены 11 новых локальных карточек. В архиве сохранён полный предыдущий машинный перевод. Непроверенные инструкции не подгружаются в основной список и не экспортируются в календарь.

Старые задачи сохраняют ID и галочки. Если карточка исключена, в плане остаётся её заголовок, пометка «Архив» и ссылка на исходник. Старые закладки тоже открывают архивную пометку, а не исчезают. Для существенно другого действия создаётся новый ID, чтобы не подменять смысл сохранённой задачи.

## Файлы

- `content/build_localized.py` — редакционные тексты, источники и воспроизводимая сборка.
- `content/sources.json` — реестр источников с датами сверки.
- `assets/advice.ru.json` — текущая подборка и безопасный индекс исключённых записей.
- `assets/advice.json` — 608 оригинальных китайских записей.
- `assets/archive/advice.machine.ru.json` — предыдущий непроверенный машинный перевод.
- `tools/translate.py` и `tools/polish.py` — прежний процесс перевода; теперь пишет только в архив и не перезаписывает российскую редакцию.

При обновлении сведений отредактируйте карточку и дату проверки источника в `content/build_localized.py`, затем запустите:

```sh
python3 content/build_localized.py
python3 tests/data.py
node --check app.js
```

## Запуск и публикация

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Нужен HTTP-сервер: загрузка данных через `file://` не поддерживается.

GitHub Pages настроен на GitHub Actions. Push в `main` запускает `.github/workflows/pages.yml`: проверка данных и JavaScript, затем публикация файлов сайта. Ресурсы используют относительные пути.

## Проверки в браузере

С запущенным HTTP-сервером:

```sh
npm install --prefix /tmp/life-bloom-browser playwright
NODE_PATH=/tmp/life-bloom-browser/node_modules node tests/browser.cjs
```

`CHROME_PATH` задаёт путь к Chrome (по умолчанию macOS), `TEST_URL` — адрес проверяемого сайта. Тест охватывает 4 размера экрана, фильтры региона и источников, план, импорт/экспорт, календарь, продолжение чтения и миграцию сохранений из версии с 608 карточками.
