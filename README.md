# Life in Bloom — Россия и Москва

[Открыть сайт](https://jollu8.github.io/life-tutor/)

Российская редакция руководства о повседневной жизни: **619 карточек в 33 темах** — все **608 исходных советов** и 11 местных дополнений. Из них 15 относятся к Москве, 268 — к России, 336 — общие. Обновление: 29 сентября 2026 года.

## Что есть на сайте

- Компактный голубой интерфейс для телефона и компьютера.
- «С чего начать»: три подборки по три шага — освободить время, защитить важное в телефоне и сдвинуть дело с места.
- Кнопка «Поделиться» копирует прямую ссылку вида `#advice=14-10`; по ней открывается совет с раскрытыми подробностями. Если буфер обмена недоступен, ссылку можно скопировать из диалога.
- Раскрытые пояснения сохраняются при обновлении списка, а фокус — при отметке выполнения; после удаления фокус переходит к соседней карточке.
- Поиск, темы, фильтры «Россия и Москва», «Вся Россия», «Только Москва».
- Отдельное указание основания: официальный источник, рекомендации организаций, практическая идея или редакционная адаптация. Старые оценки A/B/C не переносятся на новые тексты.
- Личный план, собственные задачи, галочки, экспорт и импорт JSON.
- Продолжение чтения с сохранением карточки, подборки, региона, фильтров и раскрытых подробностей.
- События `.ics` и Google Calendar; в описание попадают российский текст и актуальные источники карточки.

Данные пользователя остаются в `localStorage` текущего браузера. Аккаунтов, аналитики и облачной синхронизации нет. Очистка данных сайта удаляет локальный прогресс; резервная копия переносит задачи, но не закладку чтения.

## Редакционная политика

Это самостоятельная адаптация, а не буквальный перевод. Все 608 исходных идентификаторов опубликованы; ни один исходный совет больше не исключён из выдачи. Дополнительные 11 карточек сохранены отдельно. Китайские правовые процедуры, телефонные номера, возрастные пороги и финансовые программы не переносятся на Россию.

Восстановленные пояснения написаны отдельно для каждого совета в `content/restored.tsv`. Сомнительные универсальные назначения заменены вопросами для индивидуальной медицинской оценки. Бытовые идеи не получают выдуманных оценок эффективности; для услуг не обещано автоматическое назначение. Советы о поездках и учёбе за границей сохранены для российского читателя.

У ранее подготовленных карточек сохранены их основания и источники. Новые карточки помечены **«Редакционная адаптация»**: это самостоятельный практический текст, а ссылки указывают нормативную базу, справочный материал или службу для уточнения. Ссылка не означает, что организация одобрила всю карточку. Даты обновления текста и сверки ссылок хранятся отдельно. Это не индивидуальная экспертиза врача или юриста.

Старые задачи сохраняют ID, галочки и закладки. Ранее архивные карточки снова открываются с полным текстом и календарём. Для неизвестного ID остаётся безопасная заглушка без потери отметки. Архив машинного перевода хранится только для истории и не используется как текст активных карточек.

## Файлы

- `content/build_localized.py` — ранее опубликованные тексты и воспроизводимая сборка.
- `content/restore.py`, `content/restored.tsv`, `content/title_overrides.tsv` — восстановленные тексты, исправления заголовков, применимость и справочные ссылки.
- `content/sources.json` — реестр источников с датами сверки.
- `assets/advice.ru.json` — все 619 опубликованных карточек; индекс исключённых записей пуст.
- `assets/advice.json` — 608 оригинальных китайских записей.
- `assets/archive/advice.machine.ru.json` — предыдущий непроверенный машинный перевод.
- `tools/translate.py` и `tools/polish.py` — прежний процесс перевода; теперь пишет только в архив и не перезаписывает российскую редакцию.

При обновлении сведений отредактируйте соответствующий текст и метаданные в `content/`, затем запустите:

```sh
python3 content/build_localized.py
python3 tests/data.py
node --check app.js
```

## Запуск и публикация

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Нужен HTTP-сервер: загрузка данных через `file://` не поддерживается.

GitHub Pages настроен на GitHub Actions. Push в `main` запускает `.github/workflows/pages.yml`: проверка данных и JavaScript, затем публикация файлов сайта. Ресурсы используют относительные пути.

## Проверки в браузере

С запущенным HTTP-сервером:

```sh
npm install --prefix /tmp/life-bloom-browser playwright
NODE_PATH=/tmp/life-bloom-browser/node_modules node tests/browser.cjs
```

`CHROME_PATH` задаёт путь к Chrome (по умолчанию macOS), `TEST_URL` — адрес проверяемого сайта. Тест охватывает стартовые подборки, прямые ссылки, сохранение раскрытия и фокуса, 4 размера экрана, фильтры региона и источников, план, импорт/экспорт, календарь, продолжение чтения и миграцию сохранений из версии с 608 карточками.
